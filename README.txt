Folder structure:

    (put the existing portfolio assets here)

Animation GIFs from Instagram:

1. Download or export your own Instagram animation content. Only use content
    you own or have permission to publish.
2. Convert the clip to GIF if it is downloaded as MP4.
3. Put the GIF files in assets/ and name them animation-01.gif,
    animation-02.gif and animation-03.gif.
4. Open index.html. The animation cards will show the GIFs automatically.
5. To add more animations, copy a card in the ANIMATION CONTENT section and
    update its title, type, data-src and image source.

The original HTML was reorganized into separate HTML, CSS and JavaScript files.
The content, class names, asset paths and behavior are kept compatible with the
uploaded version.

Open the project folder in VS Code and use Live Server on index.html.
